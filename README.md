# Replication data and code

This repository reconstructs the deterministic statistical results in the
accepted version of “Attention or Backlash: How English Protest Signs Influence
Campaign Outcome” from frozen, merged analysis data. It also validates the
accepted power and bootstrap summaries against archived results from the
original code stack; portable scripts for independent stochastic recomputation
are included. Raw-source merging and image processing are outside scope.

`LianMurdie2026_shortJCR_Appendix.pdf` is the 25-page JCR online appendix.
`Lian_Murdie_2026_Full_Online_Appendix.pdf` is a full replication companion
that preserves the complete analysis stack.

**AI usage notice:** AI tools were used for coding assistance and cleanup; the
authors reviewed the resulting code and documentation.

## Quick start

Use R 4.3 or newer and run this command from the repository directory:

```sh
Rscript --vanilla run_all.R
```

The pipeline checks the supplied inputs, fits the models, builds the tables and
figures, and compares the results with the accepted references. It stops when a
required input, package, model, output, or comparison fails.

The required R packages and tested versions are listed in
[`environment/`](environment/). The pipeline does not install software. Figure
generation also requires a Cairo-capable R installation and Poppler's
`pdftoppm` command. The package was verified on macOS; Linux users should
provide the same R packages and system tools. A stock Windows workflow has not
been validated.

A clean relocated run on August 31, 2026, using R 4.4.2 completed all 25 stages,
passed 74 of 74 validation checks, and freshly produced all 79 registered
outputs. Each run recreates its own local `audit/` evidence; those transient
files are intentionally not versioned.

The analysis begins with three supplied files:

- `data/df_final.csv`: 101 campaign-location observations.
- `data/df_navco21_panel.csv`: 65 source-campaign-year observations.
- `data/h3_additional_moderators.csv`: the additional campaign-period measure
  used in one appendix analysis.

These files incorporate variables derived from NAVCO, V-Dem, QoG, WDI,
AidData, Polity, and the article's original measurement workflow. The package
does not redistribute raw protest photographs, image-level annotations, or the
upstream source files used in the original merge.

## Results included

The full run covers:

- Main Tables 1–4 and the three model-based article figures.
- The 25-page JCR appendix's selected Tables C1–C12.
- Full replication-appendix Tables C1–C26 and Figures C1–C2.
- The model diagnostics, robustness checks, power summaries, and plotted values
  associated with those results.

The [accepted specification inventory](docs/accepted_spec_inventory.md) maps
the twelve JCR tables to their full-appendix counterparts.

The publication gallery also includes descriptive and model-training plots
that are part of the accepted article or appendix but are not regenerated by
the statistical pipeline.

The package reproduces numerical content rather than journal typesetting.
Table layout differences do not affect validation when the estimates,
uncertainty measures, sample information, diagnostics, and plotted values agree
with the accepted references.

The models are refitted and the estimates, diagnostics, and plot data are
checked against accepted references. In the same run, the reader-facing
table-body files are copied from the accepted tables to preserve the published
display. Those table-body files are archival presentation copies, not
independent validation evidence.

Of 32 table-display components, 28 are independently rebuilt; 26 match exactly,
while C4 and C8 retain three accepted last-digit standard-error values from two
disclosed nonconverged archival fits. C25 and the three C26 panels are
materialized from separately validated accepted diagnostics or stochastic
archives.

## Validation and interpretation

Thirty of 140 accepted fits show convergence or monotone-likelihood warnings in
a post-acceptance check. Their published values are preserved for fidelity and
identified in the [detailed fit notes](output/diagnostics/accepted_fit_status_all.csv).

Accepted power and bootstrap summaries come from verified archived results.
The accepted generator source snapshots are included under
`reference/accepted/generators/`; only the machine-specific project root was
replaced by `ACCEPTED_ANALYSIS_ROOT`, leaving the algorithms and seed contracts
unchanged. They still rely on legacy fit objects. Portable optional
recomputation scripts use independent random streams and cannot replace the
accepted outputs. An
invalid counting-process Cox power simulation is excluded, and no claim is made
from it. The [accepted specification
inventory](docs/accepted_spec_inventory.md) provides the complete technical
mapping for readers who need it.
